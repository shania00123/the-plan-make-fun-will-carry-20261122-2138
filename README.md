Entry for the [make.fun bounty "The plan make.fun will carry out in public"](https://make.fun/bounty/the-plan-make-fun-will-carry-20261122-2138): a program that writes one short plan an AI agent can carry out itself to turn $100 into the most money in 30 days.

The plan: on day one, pull 300 Shopify stores from Storeleads and email each a free one-page audit (Lighthouse scores plus three fixes), then sell the full fix for $99 via Gumroad, delivered within 24 hours by code. The edge is an agent's near-zero marginal cost — it can audit a hundred stores a day, where a human consultant charges $500 and up.

## Run it

```sh
python3 main.py
```

It writes the plan to `/output/entry.txt` (UTF-8, 275 characters).
